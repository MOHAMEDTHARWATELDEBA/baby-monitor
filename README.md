# 👶 Baby Monitor — جهاز مراقبة البيبي بالويب أب

موبايل يتحط جنب البيبي ككاميرا ومايك، وموبايل تاني (أو كمبيوتر) تشوف وتسمع وتتكلم مع البيبي **من أي مكان**، مع كشف حركة وصوت وتنبيهات فورية.

**يعمل مباشرة من GitHub Pages — بدون سيرفر خاص.**
الرابط المباشر: https://MOHAMEDTHARWATELDEBA.github.io/baby-monitor/

بُني بـ **WebRTC (فيديو/صوت مباشر Peer-to-Peer) + PeerJS** للإشارات. الفيديو والصوت يمشيان مباشرة بين الموبايلين، و PeerJS Cloud المجاني بس بيوصّلهم ببعض أول مرة.

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 📷 فيديو لايف | كاميرا موبايل البيبي بجودة حتى 720p |
| 🔊 صوت لايف | تسمع البيبي لحظة بلحظة |
| 🎙️ تحدث مع البيبي | صوتك يطلع من موبايل البيبي (زر التحدث) |
| 🏃 كشف حركة | مقارنة فريمات الكاميرا، حساسية 3 مستويات، تنبيه فوري |
| 🔊 كشف صوت عالي | لو البيبي بيعيّط أو عمل صوت عالي، يوصلك تنبيه |
| 🔔 تنبيهات | اهتزاز + صوت تنبيه + سجل بالتوقيت عند الأب/الأم |
| 📸 التقاط صورة | احفظ لقطة من البث بضغطة واحدة |
| 🎵 تهويدة + 💡 إضاءة ليلية | من موبايل البيبي نفسه |
| 🔒 غرف بكود | كل غرفة بكود 6 حروف، محدش يدخل غير اللي معاه الكود |

## 🌍 التشغيل من GitHub Pages (الطريقة الأساسية)

1. ارفع المشروع على GitHub (الريبو موجود بالفعل).
2. في الريبو: Settings ← Pages ← Build and deployment ← Deploy from a branch.
3. اختر Branch: `main`، و Folder: `/docs`، ثم Save.
4. بعد دقيقة تقريبًا، افتح: **https://MOHAMEDTHARWATELDEBA.github.io/baby-monitor/**

> ملاحظة: GitHub Pages بيوفر HTTPS تلقائيًا، وده ضروري عشان الكاميرا والمايك يشتغلوا في المتصفح.

## 📱 طريقة الاستخدام

1. افتح الرابط من **موبايل البيبي** ← اضغط **إنشاء غرفة جديدة**.
2. هيطلع لك **كود غرفة** من 6 حروف (مثال: `K7M2Q9`) — الصفحة هتطلب إذن الكاميرا والمايك، وافق عليها.
3. حط الموبايل جنب البيبي، ووصّله بالشاحن، وسيب الشاشة مفتوحة.
4. افتح نفس الرابط من **موبايلك** ← اكتب كود الغرفة ← **دخول كأب / أم**.
5. هتشوف البث المباشر. اضغط **🎙️ التحدث** عشان البيبي يسمعك.
6. أي حركة أو صوت عالي هيوصلك تنبيه فورًا في صفحة المشاهدة.

### نصائح مهمة
- خلّي موبايل البيبي في الشاحن طول الوقت.
- فعّل منع إطفاء الشاشة — التطبيق بيحاول يعمل ده تلقائيًا (WakeLock)، ولو المتصفح رفض، غيّر إعدادات الشاشة يدويًا.
- جرّب التهويدة والإضاءة قبل النوم.
- لازم موبايل البيبي يبقى مفتوح على صفحة الكاميرا قبل ما تدخل من موبايلك، وموبايل الأب بيعيد المحاولة كل 3 ثوانٍ لحد ما يلاقيه.

## 🚀 التشغيل محليًا (للتجربة)

```bash
npm install
npm start
# افتح: http://localhost:3000
```

> الكاميرا والمايك في المتصفح يتطلبان **HTTPS** أو **localhost**.

## 🌍 بديل: النشر على Render (اختياري)

لو فضّلت سيرفر خاص بدل PeerJS Cloud:
1. ادخل [render.com](https://render.com) ← New ← Web Service ← اختر الريبو.
2. Build Command: `npm install` — Start Command: `npm start`
3. بعد النشر هتاخد رابط `https://baby-monitor-xxxx.onrender.com` — افتحه من الموبايلين.

ملف `render.yaml` موجود في الريبو لتسهيل النشر من Render (Blueprint).

## 🔧 كيف يعمل تقنيًا؟

- **PeerJS**: سيرفر إشارات مجاني (0.peerjs.com) يسجّل كل موبايل بمعرّف `bm-<الكود>-baby` و `bm-<الكود>-parent`، ويوصّل مكالمة WebRTC وقناة بيانات بينهما. لا فيديو ولا صوت يعدّي عليه.
- **WebRTC**: اتصال مباشر P2P للفيديو والصوت، بأقل تأخير.
- **STUN**: سيرفرات Google المجانية لاكتشاف العناوين واختراق NAT.
- **كشف الحركة**: مقارنة فريمات مصغّرة (160×120) كل 0.5 ثانية، بنسبة اختلاف فوق عتبة الحساسية، مع فترة تهدئة 5 ثوانٍ. التنبيه يتبعت عبر قناة بيانات PeerJS.
- **كشف الصوت**: تحليل مستوى الصوت عبر `AnalyserNode`، تنبيه عند تجاوز 25%.
