# 👶 Baby Monitor — جهاز مراقبة البيبي بالويب أب

موبايل يتحط جنب البيبي ككاميرا ومايك، وموبايل تاني (أو كمبيوتر) تشوف وتسمع وتتكلم مع البيبي **من أي مكان**، مع كشف حركة وصوت وتنبيهات فورية.

بُني بـ **WebRTC (فيديو/صوت مباشر Peer-to-Peer) + Node.js + Socket.io** للإشارات.

## ✨ المميزات

| الميزة | الوصف |
|---|---|
| 📷 فيديو لايف | كاميرا موبايل البيبي بجودة حتى 720p |
| 🔊 صوت لايف | تسمع البيبي لحظة بلحظة |
| 🎙️ تحدث مع البيبي | صوتك يطلع من موبايل البيبي (زر التحدث) |
| 🏃 كشف حركة | مقارنة فريمات الكاميرا، حساسية 3 مستويات، تنبيه فوري |
| 🔊 كشف صوت عالي | لو البيبي بيعيّط أو عمل صوت عالي، يوصلك تنبيه |
| 🔔 تنبيهات | اهتزاز + صوت تنبيه + سجل بالتوقيت عند الأب/الأم |
| 📸 التقاط صورة | احفظ لقطة من البث بضغطة واحدة |
| 🎵 تهويدة + 💡 إضاءة ليلية | من موبايل البيبي نفسه |
| 🔒 غرف بكود | كل غرفة بكود 6 حروف، محدش يدخل غير اللي معاه الكود |

## 🚀 التشغيل محليًا (للتجربة)

```bash
npm install
npm start
# افتح: http://localhost:3000
```

> ⚠️ الكاميرا والمايك في المتصفح يتطلبان **HTTPS** أو **localhost**.
> للتجربة من الموبايل على نفس الواي فاي: شغّل السيرفر، وافتح `http://<IP-الكمبيوتر>:3000` — بعض المتصفحات سترفض الكاميرا على HTTP غير localhost. الحل الأكيد: النشر على HTTPS (الخطوة التالية).

## 🌍 النشر على الإنترنت (عشان يشتغل من أي مكان)

أسهل خيار مجاني: **Render**

1. ارفع المشروع على GitHub (شوف قسم GitHub تحت).
2. ادخل [render.com](https://render.com) → New → Web Service → اختر الريبو.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. بعد النشر هتاخد رابط `https://baby-monitor-xxxx.onrender.com` — افتحه من الموبايلين، هو ده رابطك الدائم.

بدائل مجانية مشابهة: Railway, Fly.io, Cyclic — نفس الخطوات تقريبًا.

## 📱 طريقة الاستخدام

1. افتح الرابط من **موبايل البيبي** → اضغط **إنشاء غرفة جديدة**.
2. هيطلع لك **كود غرفة** من 6 حروف (مثال: `K7M2Q9`) — الصفحة هتطلب إذن الكاميرا والمايك، وافق عليها.
3. حط الموبايل جنب البيبي، ووصّله بالشاحن، وسيب الشاشة مفتوحة.
4. افتح نفس الرابط من **موبايلك** → اكتب كود الغرفة → **دخول كأب / أم**.
5. هتشوف البث المباشر. اضغط **🎙️ التحدث** عشان البيبي يسمعك.
6. أي حركة أو صوت عالي هيوصلك تنبيه فورًا في صفحة المشاهدة.

### نصائح مهمة
- خلّي موبايل البيبي في الشاحن طول الوقت.
- فعّل منع إطفاء الشاشة — التطبيق بيحاول يعمل ده تلقائيًا (WakeLock)، ولو المتصفح رفض، غيّر إعدادات الشاشة يدويًا.
- جرّب التهويدة والإضاءة قبل النوم.
- الصوت والفيديو بيمشوا مباشرة بين الموبايلين (WebRTC)، السيرفر بس بيوصّلهم ببعض.

## 🔧 كيف يعمل تقنيًا؟

- **Socket.io**: غرف + تمرير رسائل WebRTC (offer/answer/ICE) + التنبيهات.
- **WebRTC**: اتصال مباشر P2P للفيديو والصوت، بأقل تأخير.
- **STUN**: سيرفرات Google المجانية لاكتشاف العناوين واختراق NAT.
  - في شبكات صارمة جدًا قد تحتاج TURN — أضف بياناته في `rtcConfig` في ملفي `baby.js` و `parent.js`.
- **كشف الحركة**: مقارنة فريمات مصغّرة (160×120) كل 0.5 ثانية، بنسبة اختلاف فوق عتبة الحساسية، مع فترة تهدئة 5 ثوانٍ.
- **كشف الصوت**: تحليل مستوى الصوت عبر `AnalyserNode`، تنبيه عند تجاوز 25%.
